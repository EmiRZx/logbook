# inbox

Drop anything that should become a logbook entry here: a certificate PDF or screenshot, an
acceptance or award email saved as .eml or .txt, a list of links, a few lines of notes. Then tell
an agent "process the inbox" (or "inbox'ı işle"). The procedure is in ../AGENTS.md.

Files stay here and pile up; agents copy what they need and never move or delete anything.
`python tools/logbook.py check` lists the ones no entry covers yet.

Everything in this folder except this file is gitignored.
